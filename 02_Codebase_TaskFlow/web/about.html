Aucune donnée réelle

Les dix-huit demandes affichées sont fictives. Aucune donnée personnelle, aucune référence client, aucun secret technique. Ce projet respecte la section 5 du guide de sécurité Transactis.

Aucun JavaScript

Ce projet est volontairement écrit en HTML et CSS uniquement, sans une ligne de JavaScript, pour rester accessible à un public débutant. Les participants qui veulent travailler sur du code avec logique disposent de la piste Java, dans le dossier voisin.

TaskFlow — codebase d'exercice. Aucune donnée réelle.
