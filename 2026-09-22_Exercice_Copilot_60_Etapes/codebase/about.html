À propos de TaskBoard

TaskBoard est un petit projet fictif de tableau de tâches, en HTML, CSS et JavaScript, construit pour l'exercice pratique « 60 étapes GitHub Copilot ».

Le projet est volontairement incomplet : les cartes de tâches existantes sont écrites directement dans le HTML, mais le formulaire de la page d'accueil n'est pas encore relié au script js/app.js, qui contient aussi un bug volontaire et plusieurs TODO. L'objectif est de pratiquer GitHub Copilot sur un vrai petit projet multi-fichiers (plusieurs pages, plusieurs feuilles de styles, un script) pour aller du prompt le plus simple jusqu'à l'orchestration d'agents.

Consultez docs/architecture.md pour le détail de l'organisation des fichiers.
